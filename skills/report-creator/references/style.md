# Default report style

Read before laying out or rendering. These are this user's defaults. An assignment template or newer user instruction overrides them.

## Fonts

- Times New Roman for all authored text: headings, body, captions, tables, header, footer. Table numbers and reported scores stay in Times New Roman.
- Inconsolata for inline code, code blocks, and code identifiers. Copy `assets/fonts/Inconsolata-Regular.otf` and `assets/fonts/OFL-Inconsolata.txt` from this skill into the report project and reference them by project-relative path. No global install needed.
- LaTeX: stop math mode from changing table digits, e.g. `$\text{0.133726} \pm \text{0.000646}$`. Check the rendered table.

## Body

- 12 pt, fully justified, 1.2 line spacing. Keep this spacing under a page limit: cut repetition or improve layout instead.
- No semicolons in authored prose: split the sentence or use a comma or colon. Literal code and quoted material keep their syntax. Flag any conflict with an explicit no-symbol requirement.
- No bold in report prose unless the user asks.

## Header and footer

- Centered header, normal weight, no bold. Line 1: full course name. Line 2: assignment number and report title. Line 3 (smaller): student name and ID. Separate fields with commas, not vertical bars. Thin horizontal rule below. Title block may be single-spaced.
- Verify the assignment number from the instructions, not from a reference image.
- Footer: only a centered page number, 12 pt Times New Roman. No label, text, or rule.

## Hierarchy and placement

- Show hierarchy with alignment, spacing, and indentation, not bold. Main section headings left-aligned.
- Lettered parts: label and upright heading above a slightly inset body, narrow label gutter, more space before headings than between paragraphs. Do not put every heading and paragraph on the same left edge.
- Center tables and equations in the content area.
- Each figure caption directly below its image, centered on the image, kept together with it. Preserve original screenshot typography.
- Keep code whitespace and alignment intact.
- Let content flow naturally. Keep headings with following content. No orphaned lines, caption-only pages, or unneeded forced breaks.
